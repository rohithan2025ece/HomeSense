# HomeSense

## An IoT-Based Smart Home Organization and Assistance System for Independent Living of Visually Impaired Individuals

### Overview
HomeSense is a conceptual IoT-based smart home assistance system designed to improve independent living for visually impaired individuals. The system uses RFID technology, ESP32, and voice interaction to help users organize and locate household items privately and efficiently.

### Features
- Voice-based item search
- RFID-tagged household objects
- Smart Memory Mode
- Privacy-preserving design
- Affordable IoT implementation
- Scalable smart home architecture

### Technologies
- ESP32
- RFID (RC522)
- Flutter
- Firebase
- Arduino IDE
- Speech-to-Text
- Text-to-Speech
